# LazeEditor

LazeEditorは、Monaco Editorライブラリを使用してLazeプログラミング言語向けの豊かなコーディング体験を提供する、Webベースのコードエディタです。

## 機能

- Laze言語のシンタックスハイライト
- 括弧のハイライトをサポートするカスタマイズ可能なエディタテーマ
- オートコンプリートとコードフォーマット
- 高品質なコーディング体験のためのMonaco Editorライブラリとの統合

## 要件

- システムにNode.jsとnpmがインストールされていること

## 使用方法

1. リポジトリをクローンします:
   ```
   git clone https://github.com/your-username/LazeEditor.git
   ```

2. 依存関係をインストールします:
   ```
   cd LazeEditor
   npm install
   ```

3. プロジェクトをビルドします:
   ```
   npm run build
   ```

4. 開発サーバーを起動します:
   ```
   npm start
   ```

   LazeEditorは `http://localhost:8080/` で利用可能になります。
